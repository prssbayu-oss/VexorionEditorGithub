[![Author](https://img.shields.io/badge/author-Prasetyo%20Bayu%20Widodo-blue)](https://github.com/prssbayu-oss)

A high-performance, modern GitHub web interface and code explorer developed by **Prasetyo Bayu Widodo** (`prssbayu-oss`). Built with React 19, TypeScript, Tailwind CSS, and Motion.

---

## ✨ Features

- ⚡ **Real-Time GitHub Synchronization**: Live sync with the official GitHub API (`api.github.com`) to display actual repositories, branches, commits, issues, and files.
- 📂 **Complete Code Explorer**: Fast file tree navigation, branch switcher, and syntax-highlighted code viewer for real project files.
- 🔀 **Pull Requests & Diff Engine**: Unified & split diff views with colorized additions/deletions, line number tracking, and comment threads.
- 🐛 **Issue Tracker**: Full issue lifecycle management, state filters (Open/Closed), multi-label tags, and discussion timeline.
- 🚀 **GitHub Actions CI/CD Viewer**: Visual workflow run status, step-by-step logs, artifact tracking, and duration timers.
- 📊 **Insights & 52-Week Contribution Matrix**: Interactive GitHub-style contribution heatmap, language distribution bars, and repository pulse.
- 🔍 **Spotlight Command Palette (`Ctrl+K` / `⌘K`)**: Instant fuzzy file searching and quick action dispatcher.
- 📱 **Responsive & Mobile-Ready**: Polished layout designed to look pristine on mobile, tablet, and desktop viewports.

## 🚀 Quick Start

### 1. Clone the repository
```bash
git clone https://github.com/prssbayu-oss/VexorionEditorGithub.git
cd VexorionEditorGithub
```

### 2. Install dependencies
```bash
npm install
# or
bun install
```

### 3. Run development server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

## 🛠️ Tech Stack

- **Framework**: React 19 + TypeScript
- **Styling**: Tailwind CSS + Lucide Icons
- **Animations**: Motion (`motion/react`)
- **Build Tool**: Vite
- **Data Engine**: Reactive Git & GitHub API Engine
